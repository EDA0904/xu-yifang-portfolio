# 許禕芳個人網站

這是一個純靜態網站，不需要安裝套件。

## 本機預覽
直接雙擊 `index.html` 即可。若瀏覽器對本機影片有限制，可在此資料夾開啟簡單伺服器：

```bash
python -m http.server 8000
```

然後開啟 `http://localhost:8000`。

## 上線方式
可直接把整個資料夾部署到 GitHub Pages、Netlify、Cloudflare Pages、Vercel static site 等服務。

## 內容定位
- 不把本人包裝成藝術創作者。
- 核心定位：餐飲現場的務實底盤 + 對跨領域的好奇 + 靈感／聯想 + 自主找方法。
- 作品區的功能是展示思考方式，不是宣稱專業藝術技能。
- 公開聯絡只保留 Email，不顯示電話或住址，也不提供履歷下載。

## 檔案
- `index.html`：頁面內容
- `styles.css`：視覺樣式
- `script.js`：手機選單、材料揭曉、捲動動畫
- `assets/`：作品圖片、影片
